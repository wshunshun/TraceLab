# TraceLab · 图片转 SVG

TraceLab 是一款在浏览器本地运行的 PNG、JPG / JPEG 转 SVG 工具，适合标志、图标和文字图稿。导出的 SVG 由可编辑的路径和填充组成，不是把原始位图嵌进 SVG。图片不会上传，安装依赖后可离线使用。

## 功能

- **轮廓追踪**：可调整颜色数量、细节保留、边缘平滑和去除杂点，减少浅底标志的 JPEG 晕边。
- **渐变拟合**：在适合的标志上分别拟合轮廓和颜色，输出原生 SVG 线性渐变，减少渐变被切成阶梯色块的情况。
- **同步对比**：原图和 SVG 可以同步缩放、拖动，也可以单独显示其中一侧。
- **SVG 导出**：保留原图尺寸，支持在矢量编辑器中修改路径和填充。

## 快速开始

准备 Node.js（含 npm）、Python 3，以及支持 WebAssembly 和 Web Worker 的现代浏览器。克隆或下载仓库后，在项目根目录运行：

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173/>。请通过本地服务访问，不要直接双击 `index.html`；处理图片所需的脚本和 WebAssembly 由本地服务提供。

1. 拖入或选择一张 PNG、JPG 或 JPEG 图片。
2. 保持「自动」，或按下表选择适合的图像类型，然后点击「开始转换」。
3. 用滚轮或 `−` / `＋` 查看细节，拖动切换观察区域，点击缩放百分比恢复适应窗口。
4. 确认效果后点击「导出 SVG」。

## 转换模式

| 模式 | 适用图片 | 输出特点 |
| --- | --- | --- |
| 自动（默认） | 不确定如何选模式时 | 优先识别浅底标志的渐变，无法拟合时回退到「标志 / 文字」。 |
| 标志 / 文字 | 平涂标志、图标、文字 | 以纯色填充描摹轮廓，并抑制浅底图的压缩晕边。 |
| 渐变标志 | 浅色纯底、具有平滑渐变的标志 | 对识别出的区域拟合可编辑的 SVG 线性渐变，不受「颜色数量」滑块限制。 |
| 照片 / 复杂渐变 | 照片或纹理复杂的图片 | 通过色块近似原图，不会无损重建纹理或光影。 |

## 使用建议与限制

- **看笔画**：先保持「细节保留」为 100%，并关闭「额外去除杂点」。细小笔画消失时，先降低平滑程度再重新转换。
- **看渐变**：蓝绿过渡等明显渐变被压成色块时，选择「自动」或「渐变标志」，不必一味提高颜色数量。
- **看透明度**：「保留原图透明区域」只保留原图已有的透明像素，不会自动移除不透明的白底。
- **大图与小字**：追踪分辨率受长边 4096 像素、约 1200 万像素的限制。低分辨率和高压缩图片中的细节只能估算，正式印刷建议优先使用原始矢量文件。

## 项目结构

项目使用原生 HTML、CSS、JavaScript 和 `vtracer-browser`，不需要前端构建步骤。

| 文件 | 用途 |
| --- | --- |
| [`index.html`](index.html)、[`styles.css`](styles.css) | 页面和预览布局 |
| [`main.js`](main.js) | 本地图片读取、转换参数、同步预览和 SVG 下载 |
| [`logo-preprocess.js`](logo-preprocess.js) | 检测浅色背景、抑制轮廓晕边 |
| [`gradient-logo.js`](gradient-logo.js) | 渐变区域分割和 SVG 填充拟合 |
